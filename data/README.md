# MediAssist Data Directory

This directory contains demonstration datasets, synthetic clinical cohorts, and sample radiographs used by MediAssist.

## Files & Structure
- `triage_dataset.csv`: Curated clinical presentation dataset (60 samples across Emergency Warning, Urgent Assessment, and Routine Assessment categories) based on Emergency Severity Index (ESI) and Manchester Triage criteria.
- `demo_patients.json`: Synthetic demonstration patient records with multi-modal presentations (symptoms, vitals, lab panels, radiograph references).
- `sample_xrays/`: Directory containing anatomically plausible synthetic chest radiographs in PNG format (`normal_sample.png`, `cardiomegaly_sample.png`, `effusion_sample.png`, `infiltration_sample.png`).

## Privacy & Ethics
All data in this directory is strictly synthetic and anonymized. No real Patient Health Information (PHI) is present.
